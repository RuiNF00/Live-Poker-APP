# Opções de marca

Dez propostas de nome e identidade visual para a app de póquer live. Cada uma tem logótipo, ícone, paleta, tipografia, o ecrã de registar mão com a marca aplicada e a pré-visualização de uma mão partilhada.

Abrir `opcoes-de-marca.html` (fragmento HTML; as fontes vêm do Google Fonts).
